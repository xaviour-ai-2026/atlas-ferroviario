# Seguridad / Security

Atlas Ferroviario es un proyecto informativo y **no es un sistema de seguridad ferroviaria**. Para emergencias,
llama al 112; para información oficial, consulta a Renfe y Adif.

## Cómo informar de una vulnerabilidad

No abras una incidencia pública. Usa el **informe privado de vulnerabilidades** de GitHub (pestaña *Security* →
*Report a vulnerability*). Incluye qué has encontrado, cómo reproducirlo y su posible impacto. Responderemos lo
antes posible; es un proyecto voluntario sin plazos garantizados.

En alcance: este código, el sitio público y su API de solo lectura. Fuera de alcance: los sistemas y datos de
Renfe, Adif, OpenStreetMap, OpenFreeMap u OpenRailwayMap. Infórmales directamente. No hagas pruebas de carga ni de
denegación de servicio, no accedas a datos de terceros y no intentes eludir los límites de uso.

## Reporting a vulnerability (English)

Please do not open a public issue. Use GitHub's **private vulnerability reporting** (Security tab → Report a
vulnerability) with steps to reproduce and the likely impact. No load or denial-of-service testing, please.
